# ai_for_medicine

Notebooks Colab et données des cours de médecine publiés sur [ML-Arena](https://ml-arena.com).

| Dossier | Cours |
| --- | --- |
| [`python-medecine/`](python-medecine/) | *Python pour la médecine* — 8 séances, initiation à Python et à l'analyse de données |
| [`ia-medecine/`](ia-medecine/) | *IA pour la médecine* (DFGSM2) — 3 séances de TP et un projet d'apprentissage automatique |

Chaque dossier contient `notebooks/` (un notebook d'exercices et sa correction
`-correction`, à ouvrir dans Google Colab) et `donnees/` (les jeux de données que
les notebooks téléchargent).

Les notebooks sont générés depuis le dépôt source des cours ; ne pas les modifier ici.
